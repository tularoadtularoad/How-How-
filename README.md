# Оружейная — тир с модульным оружием (three.js)

Восемь автономных страниц в `weapons/` — открываются двойным кликом (работают и с `file://`):
АК-74М, АКМ, Glock 18C, HK416/M416, MP5A3, Remington 870, SCAR-H, СВД.

## Структура

- `src/` — исходники. Это модули, уже выложенные esbuild в общую область видимости, поэтому
  `build.mjs` просто склеивает их по списку `build.json` в шаблон `src/template.html`.
  - `src/engine/` — движок: сцена и пост-обработка, материалы, геометрия, баллистика, эффекты,
    оптика (`pip.js` — картинка в окуляре), интерфейс, два звуковых стека
    (`audio_b/` — АК/АКМ/M416/SCAR, остальное — `audio.js` + `foley.js` + `gunshot.js`).
  - `src/weapons/` — модели и наборы модулей, `src/entries/` — точки входа.
- `weapons/*.html` — собранный результат (коммитится: это то, что открывают).

```bash
node build.mjs        # пересобрать weapons/*.html
npm i && npm test     # сквозные тесты во всех стволах (нужен Chrome/Chromium с WebGL)
```

## Управление

F / ПКМ — прицел; колесо или `+`/`−` в прицеле — кратность (у переменной оптики — её диапазон,
у постоянной 0,75…2× от штатной, у коллиматора/механики — приближение до 2×); V — другой прицел;
R — перезарядка; X — режим огня; Q — качество (авто/высокое/среднее/низкое); H — справка.
Без прицельных приспособлений можно целиться «по стволу» — глаз над верхом ствольной коробки.

## Тесты (`tests/`)

`node tests/run.mjs <weapons/файл.html> <tests/сценарий.mjs>`; без видеокарты — Xvfb + Mesa llvmpipe
(`DISPLAY=:99`), это одновременно модель очень слабого ПК. Скриншоты — в `tests/shots/`.

| Сценарий | Что проверяет |
|---|---|
| `smoke.mjs` | стрельба, перезарядка, прицел, кратность, день/ночь — без ошибок в консоли |
| `hitches.mjs` | самый долгий кадр вокруг первого/второго выстрела, перезарядки, смены времени суток и модуля |
| `modules.mjs` | каждый модуль каждого слота: касается ли оружия (сэмплы поверхности в сетке 1 мм), NaN в геометрии; с самопроверкой детектора |
| `hdr-nan.mjs` | подмешивает NaN-пиксель: в исходной версии bloom раздувал его в чёрный прямоугольник |
| `bore-sight.mjs` | прицеливание без прицела и кратность |
| `profile.mjs` | стоимость кадра по проходам (сцена, GTAO, bloom, вывод) |
